# Новый дизайн кабинета — что изменилось

28.10.2026. Перенесён дизайн из дизайн-системы «ИИ Пресс-секретарь», версия 2 «Жидкое стекло» (токены, шрифт Donbass, иконки, компоненты, пружинные анимации). Логика сервиса не менялась: маршруты, формы, `/api/tasks`, публикация и БД работают как раньше.

## Как выкатить

1. Заменить файлы проекта на файлы из архива (список ниже). Новых зависимостей нет, `requirements.txt` не менялся.
2. Перезапустить сервис (`systemctl restart …`). Шаблоны и статика подхватятся сами.
3. Настройки nginx не трогать: статику по-прежнему отдаёт FastAPI (`/static/...`), новые файлы лежат в `cabinet_service/static/press/`.
4. Если браузер показывает старый вид — это кэш: у CSS и JS стоят версии (`style.css?v=20`, `components.css?v=4`, `tokens.css?v=2`, `glass.js?v=4`, `hero-bg.js?v=13`), при следующих правках номер нужно поднимать.

В архиве нет `venv`, `users.db`, `.env` и `media/` — на сервере остаются ваши.

## Изменения в Python (небольшие, только данные для шаблонов)

**`cabinet_service/app.py`**
- После создания `templates`: глобальные `ui` (макросы иконок и логотипа из `templates/_ui.html`), `plural()` — склонение по числу, фильтр `num` — разряды через неразрывный пробел («4 096»).
- `first_name()` (фильтр `|first_name`) — имя для обращения из поля «Имя»: словарь частых имён, затем отчество и окончания фамилий («Котова Ирина Сергеевна» → «Ирина»); если в поле название организации в кавычках — обращение без имени. `greeting_for_hour()` — «Доброе утро / Добрый день / Добрый вечер / Доброй ночи»; на главной скрипт уточняет приветствие по часам пользователя.
- `render()`: в контекст добавляется `active_persona` — последний медиа-образ пользователя (карточка внизу боковой навигации). Один лишний запрос к SQLite на страницу.
- `/dashboard`: дополнительно отдаёт `recent_posts` (3 последних с картинками), `counters` (посты, картинки, опубликовано, медиа-образы) и `platform_label`.

**`database.py`**
- `get_posts_for_user()`: в SELECT добавлено поле `published` (колонка уже есть после миграции) — для статуса «Опубликован» в карточках.

## Новые файлы

- `cabinet_service/static/press/tokens.css` — цвета светлой и тёмной темы, отступы, радиусы, тени, шрифт Donbass. Сгенерирован из дизайн-системы, руками не править.
- `cabinet_service/static/press/components.css` — стили компонентов дизайн-системы (классы `ps-*`).
- `cabinet_service/static/press/fonts/` — Donbass 400/500/600/700 + лицензия SIL OFL.
- `cabinet_service/static/press/app-icon.svg` — знак (фавикон).
- `cabinet_service/static/press/glass.js` — навигация (плашка активного пункта едет к нажатому пункту сразу, до загрузки раздела), компактная панель заголовка при прокрутке, смена темы кругом, блик на стекле.
- `cabinet_service/static/press/hero-bg.js` — фон первого экрана лендинга на canvas: крупный знак целиком (одноцветная версия логотипа, без нахлёста), покачивание, дыхание и блик; сетка; свет градиента меняется по времени суток посетителя, ночью — звёзды. Цикл 24 с, пауза вне экрана и на скрытой вкладке, при «Уменьшить движение» — статичный кадр. Для проверки: `/?daypart=night&t=12` замораживает кадр.
- `cabinet_service/templates/_ui.html` — макросы `ui.icon()`, `ui.logo()`, `ui.mark()`, миниатюры шаблонов картинок.
- `cabinet_service/templates/_post_card.html` — карточка поста (главная и «Мои посты»).

## Переписанные шаблоны

`base.html` (каркас: боковая навигация, на телефоне нижняя панель и лист «Ещё», тосты, экран входа), `landing.html`, `dashboard`, `generate`, `history`, `plan`, `post_detail`, `post_edit`, `publish`, `images`, `image_generate`, `channels`, `channel_add`, `survey_list`, `survey_view`, `survey_import`, `stats`, `provider`, `tenchat`, `profile_edit`, `delete_confirm`, `login`, `register`, `presentation_tz` (отдельная страница-документ на токенах и компонентах, со сменой темы). В `survey.html` кроме шапки и раскладки исправлены ошибки анкеты: поля неактивного типа (личный бренд / компания / сообщество) отключаются и не затирают ответы; Enter переходит к следующему шагу, а сохраняет только кнопка на последнем; точки шагов — кнопки с клавиатурой; результат анализа соцсети собирается через `textContent` (без вставки HTML); ошибка сохранения — тостом.

Все `id`, имена полей форм и вызовы `/api/tasks` сохранены. В `base.html` общие помощники: `Press.fetchJSON` (распознаёт истёкшую сессию — редирект на `/login` — и показывает «Сессия истекла»), `Press.pollTask` (опрос задачи, предел 5 минут, неизвестный статус — ошибка), `Press.humanError`, `Press.toast`, `Press.plural`, `Press.openSheet` (фокус внутри листа). Системные `confirm()` заменены на лист подтверждения: форме достаточно атрибутов `data-confirm`, `data-confirm-body`, `data-confirm-ok`. Flash-сообщения об ошибках показываются красным тостом.

В `<head>` кабинета есть `speculationrules` — браузеры на Chromium заранее загружают раздел при наведении на ссылку, переход почти мгновенный. Исключены `/media/*`, экспорт .docx и `/delete-account`; POST-формы не затрагиваются.

На лендинге пример поста интерактивный: 10 медиа-образов (случайный при каждом открытии), команды правки и «Опубликовать» меняют состояние. Всё локально в браузере, на сервер ничего не уходит.

На странице поста появилась история версий с кнопкой «Вернуть» — через существующий `POST /api/posts/{id}/edit-text`, новых маршрутов нет.

## Презентация

`ИИ_Пресс-секретарь_презентация.pptx` и `.pdf` пересобраны по брендбуку: шрифт Donbass (встроен в оба файла), токены цвета, логотипы и иконки дизайн-системы, реальные экраны кабинета, тексты по правилам голоса. Отдаются по `/presentation.pptx` и `/presentation.pdf`.

Пересборка (Windows, нужны PowerPoint, Chrome и шрифт Donbass в системе; в venv — `python-pptx`, `Pillow`, `playwright`):
1. `python deploy/build_presentation_assets.py` — логотипы и иконки в PNG (`deploy/presentation_images/brand/`).
2. `python deploy/generate_presentation.py` — PPTX.
3. `powershell -File deploy\export_presentation.ps1` — встраивает шрифт и сохраняет PDF.

Экраны кабинета лежат в `deploy/presentation_images/screens/`. Старые картинки с роботом (`title_robot.png` и др.) больше не используются.

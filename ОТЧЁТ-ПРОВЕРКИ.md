## Мелочи

- 500 вместо понятной ошибки: `days=abc`, `post_id=abc`, `/survey/submit` с не-объектом или числовым `title`, импорт JSON с `"title": 123`, пароль длиннее 72 байт — бэкенд.
- Неизвестный `task_type` создаёт вечную задачу — бэкенд.
- «Статус обновлён» / «Пункт удалён» для несуществующих пунктов плана — бэкенд.
- Время постов показывается в UTC; «активный» медиа-образ неоднозначен при одинаковом времени создания — бэкенд.
- При ошибке генерации картинки пропадают шаблоны (не передаются в страницу) — бэкенд, одна строка.
- Фон лендинга не пересчитывается при изменении высоты первого экрана; тост «План готов: 1 идей» без склонения; «Пост готов» на лендинге индиго вместо зелёного; иконка «глаз» у темы и у «Показать ключ»; `code` 11,96px; капсула «ИИ» в маленьком логотипе мельче 12px; кнопки анкеты не капсулы; часть отступов не кратна 4; «Быстрый старт» 2+1 на 1440; четыре показателя в одну колонку на телефоне; параметры плана под списком на узких экранах — дизайн.
- `/presentation-tz` вне дизайн-системы, контраст кнопки 2,5:1; ссылки на PDF и PPTX дают 404 — дизайн / бэкенд.
- Подтверждения удаления — системные `confirm()`, брендбук требует лист — дизайн.
- Тексты: «⏳ Генерация...», «Ошибка сети: »+текст, «Промпт», «Tenchat», «3-10» — частично в анкете (бэкенд), частично в общих скриптах (дизайн).

## Не подтвердилось или неточно

- «Платный вызов ИИ при тестах» — не было: ключа PiAPI в `.env` нет, генерация шла по встроенным шаблонам.
- «SECRET_KEY не задан» — в локальном `.env` задан. На сервере он **обязателен**, иначе сессии слетают при каждом перезапуске.
- Публичен ли репозиторий на GitHub с паролем из `deploy/` — не проверялось. Если да, пароль уже скомпрометирован.

# Telegram Бот для предпринимателей 🤖

Бот помогает предпринимателям создавать контент для социальных сетей с помощью нейросетей.

## 🚀 Ссылка на бота

**Попробуй прямо сейчас:** [@SwiftBizAidBot](https://t.me/SwiftBizAidBot)

## 📋 Функции

- Регистрация пользователей
- Выбор из 9 видов предпринимательства
- Генерация контента для Instagram, LinkedIn, Telegram, Twitter
- Управление через кнопки

## 🛠️ Технологии

- Python
- Telebot (pytelegrambotapi)
- SQLite
- Groq API (нейросети)
